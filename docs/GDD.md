# 《替身对决》玩法策划书

> 概念阶段玩法定稿。同步页面：[策划书 Page](https://cursor.com/canvas/store-11e74b90-c235-410a-af16-dd44f06b2f06/23e1429e-b693-405f-9c74-6c5d0fdc6538)

## 一句话定位

玩家用提示词生成「像自己」的人形替身，在开阔掩体图里技能对轰求生；只有活到最后的人能带走本局替身，其余替身数据销毁。**本期不做缩圈。**

| 项 | 内容 |
|---|---|
| 品类 | 多人对抗 · 大逃杀 · 技能对轰 |
| 人数 | 每局 2–6 人 |
| 差异点 | 进场前 AI 造替身 + 胜者永久保留 / 败者销毁 |

## 核心循环

写提示词 → 生成替身 → 校验（不通过弱化重抽）→ 进局对轰（开阔·掩体）→ 只剩一人（胜者保留卡）。

败者局末替身销毁；胜者带走基础卡面（不含成长层）；保留卡再入局仍须按现行规则校验。

## 对局框架

1. 进场前造替身：提示词 → 卡面与外形规格 → 校验通过后匹配
2. 匹配开局：2–6 人，开阔场景，出生分散
3. 对轰：技能互轰 + 掩体；无缩圈，靠击倒推进残局
4. 成长：击倒或拾取均可叠层，最多 3；击倒收益略高；仅本局
5. 结算：仅一名存活保留；其余销毁

## 替身生成

- 六维：力量、速度、射程、持续力、精密动作性、成长性（各 1–5，**总和=18**）
- 技能：2 小技能 + 1 大招 + 1 被动
- 短板：至多 1 个 5；有 5 则至少 1 个 ≤2；禁止全 3
- 外形：人形，身高 1.5–2.0m；头像 / 三视图 / 3D 规格

## 六维结算口径

| 属性 | 主影响 | 口径 | 不做 |
|---|---|---|---|
| 力量 | 伤害、击退 | 伤≈基础×(0.7+0.1×力量) | 不加 CD/射程 |
| 速度 | CD、位移、受控缩短 | CD≈标称×(1.15−0.05×速度) | 不加伤害 |
| 射程 | 有效距离上限 | 超出无效 | 力量不能越帽 |
| 持续力 | 生命、耐力 | 生命≈基准×(0.75+0.08×持续力) | 无缩圈毒伤 |
| 精密 | 命中、半掩、控制精度 | 相对 3 中轴 | 不加伤害倍率 |
| 成长性 | 局内层数 | ≤3 层，击倒或拾取 | 不继承、不加开局点 |

战斗顺序：射程 → 精密 → 力量 → 持续力 → 速度 → 成长。

禁止单技能同时吃满力量+速度+射程。大招必须带代价（硬直/自伤/空窗/暴露）。

## 基准数值（中锋 TTK）

- 基准生命 1000；约 3–4 次有效小技能击杀
- 小技能伤 180–220，CD 4–6s
- 大招伤 350–450 或强控，CD 18–25s

## 操作与匹配

- 锁定第三人称（默认锁最近/受伤目标）
- 保留卡上限 3；超限须弃旧再留新
- 概念期休闲无分匹配

## 技术选型

- 客户端：**Godot 4.x 3D**
- 联网：主机权威房间同步（Godot Multiplayer / ENet 等）
- AI：API 出卡与图 + 人形模板 3D（图生模二期）

## 竖切 W0–W4

**目标：** 2 人同房，提示词出卡 → 校验 → 模板人形 → 锁定对轰 → 胜者保留≤3。

| 周 | 内容 | 状态 |
|---|---|---|
| W0 | 工程骨架、锁定相机、占位人、StandCard schema+校验 | 已接入 |
| W1 | 单机对轰、六维最小结算、掩体、成长 | 已接入 |
| W2 | 2 人房间同步、胜负保留库 | 已接入 |
| W3 | LLM/文生图、模板换装、进场 UI | 已接入（无 key 时假数据，文生图为占位色） |

竖切外不做：缩圈、排位、6 人压测、完整三视图流水线、商业化。

### 结算实现取值

策划公式不变。代码里把「≈」收成下面这些常数，方便无头对照：

- 未写入 `primary_stats` 的力量 / 速度 / 射程按中轴 3 计算（倍率 1）。绑了射程时，有效距离 = 技能射程 × (0.7 + 0.1 × 射程)。
- 半掩：精密 < 3 不中；≥ 3 命中且伤害固定 ×0.5。精密不再额外加伤。全掩直接无效。
- 小技能基础伤默认 200（钳在 180–220），大招默认 400（钳在 350–450）。标称冷却超出 4–6 秒或 18–25 秒时先钳再乘速度。
- 成长：拾取 +1、击倒 +2，硬顶 3 层。有层时伤害再乘 1 + 0.03 × 成长 × 层数；0 层为 1。层数不进保留库。
- 大招代价：硬直 0.8 秒、自伤至少 40 或已造成伤害的 12%、空窗期间受击 ×1.25、暴露 3 秒。

黑名单否定词只看命中点前 12 个字（不能 / 不会 / 不是等）。效果文案若同时写出力量、速度、射程，也算三连吃。
